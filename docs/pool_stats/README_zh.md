# 合成数据用到的候选池统计

[English](README.md) | [中文](README_zh.md) · [返回 README](../../README_zh.md)

MangaOCR-Nar-Small 的合成训练数据在设计时参考了在本评测集候选池上测得的汇总统计。本页列出这些统计，数值见 [`pool_stats.json`](pool_stats.json)，不含逐框数据。

**统计范围**：GPT-6.1 Sol 在 2,524 个候选页初筛中保留的框，去掉 Read v1.2 的页面，再去掉标为拟声词的框。印刷 8,887 框，非印刷 2,516 框。Read v1.3 4,660 个新框所在的页面包含在内。统计测于 2026-10-07 至 2026-10-09。

**生成器配置**：下表中的参数值取自训练数据所用的手写配置（V177f 与 V178 两个修订版中相同），以及印刷生成器的审计目标。

## 用来设定生成器参数的统计

| 统计（范围） | 测得 | 据此设定的参数 |
|---|---|---|
| 裁图长边，10 档（印刷） | 如 160–223 px 18.25%，224–319 px 20.18%，≥ 640 px 9.45% | 印刷生成器输出分布的审计目标（相对误差 10%） |
| 裁图长宽比，7 档（印刷） | [1.5, 2.5) 34.95%，[2.5, 4) 36.87%，[4, 6) 13.94% | 同上 |
| 标签长度（非印刷） | 1–4 / 5–8 / 9–16 / 17–32 / > 32 = 43.1 / 29.0 / 19.7 / 7.5 / 0.7% | 手写长度分档权重（去掉 > 32，其余重新归一） |
| 裁图尺度 $\sqrt{hw/n}$（非印刷） | 中位 52.2 px，p10 26.4，p90 121.3 | 手写字号分档权重（尺度除以生成器实测的 1.563，即每请求像素对应的尺度像素） |
| 墨色亮度（非印刷） | 81.3% 的裁图含纯黑像素（亮度 ≤ 2）；纯黑像素占比中位 3.6% | 逐图深色墨亮度混合分布 |
| 页面编码（1,721 个原页面） | JPEG 77%，PNG 23%；JPEG 质量 ~100 占 56%，~85 占 30%，90–95 占 11%，≤ 80 占 4% | 最终编码：PNG 概率 0.23 与 JPEG 质量混合分布 |
| 气泡黑边（非印刷） | 57.7% 的裁图可见气泡外沿；外沿暗环占比 ≥ 0.6 的占 62.3% | 以概率 0.75 只用带黑边的气泡素材 |
| 文字区外面积（非印刷） | < 1% / 1–10% / 10–30% / ≥ 30% = 43.7 / 32.0 / 13.4 / 10.9% | 以概率 0.1 让气泡紧贴文字 |

合成分布逐个统计量设定（边际分布），没有把候选池的联合分布施加到生成器上。

## 只用于对照的统计

以下统计在同一范围上测得，审查时与合成输出对照，没有据此设定参数：成像特征（纯黑、深色、纯白像素占比，纸面噪声，平坦区残差）、文本特征（长度、汉字占比、纯假名与纯标点占比）、分类器双样本检验（真实与合成）、同图笔宽离散度、文字边距、断行位置。前两项收在 `pool_stats.json` 的 `reference_only` 中。
